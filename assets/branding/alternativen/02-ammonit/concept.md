# Kreidezeit – Alternative 02: Ammonit

Ein Ammonit, das Leitfossil der Kreidezeit, ist mit Kreide auf eine Schiefertafel mit feinem Karoraster gezeichnet. So steckt das Wortspiel „Kreide/Tafel ↔ Erdzeitalter“ direkt im Bild. Die Schale ist eine echte logarithmische Spirale, die pro Windung um φ² ≈ 2,618 wächst. Dadurch ist jede Windung im Goldenen Schnitt breit: eine kleine Mathe-Pointe für Lehrkräfte. Die bernsteinfarbene Wohnkammer setzt einen warmen Akzent und trägt die Wiedererkennung auch bei 16 px. Die Rippen erinnern an aneinandergereihte Folien. Der Schriftzug in einer warmen Buch-Serife wirkt seriös und zugleich freundlich, die Unterzeile in gesperrter Grotesk ist klar und technisch.
